BlindQueue — Live Location

Phone GPS → Supabase → Live laptop dashboard

1. Sign in

Use the same account on the Android phone and laptop. Create the account once, then sign in on both devices.

Add your Supabase project URL and publishable/anon key in this file before using it.

2. Phone tracking controls

Sign in, then press “Start GPS tracking” on the Android phone and allow location permission.

This browser version tracks while the page is open and active. It is not a guaranteed all-day background tracker. For screen-off tracking, a native Android app with background-location permission is needed. Only track a person who has explicitly agreed.
